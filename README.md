# wpu-resolusi

A collection of learning plans and resolutions used to practice Git and GitHub collaboration.

[Repository](https://github.com/MirzaAlbab/wpu-resolusi)

## Features

- Personal learning goals stored in text files
- WPU content plans and resolutions
- Contributions from multiple participants

## Getting started

```bash
git clone https://github.com/MirzaAlbab/wpu-resolusi.git
cd wpu-resolusi
```

Open the text files in any editor. Use Git commits and branches to practice documenting and sharing changes.

## Development and checks

Review text changes with `git diff` before committing.

## Project notes

This is a document repository; no application build or package installation is required. The original README describes it as a place to store future WPU plans.
